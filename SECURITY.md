# Security Policy

## Scope

WAFFEN is a WAF bypass research tool for **authorized testing only**.
Vulnerabilities in WAFFEN itself (not in target WAFs) are in scope for this policy.

## Reporting a Vulnerability

**Email:** security@redeyes.uz

Please include:

- Description of the vulnerability
- Steps to reproduce
- Impact assessment
- Suggested fix (if any)

**Do not** open a public GitHub issue for security vulnerabilities.

## Response Timeline

| Stage | Timeline |
|-------|----------|
| Acknowledgement | 48 hours |
| Initial assessment | 7 days |
| Fix release (critical) | 7 days |
| Fix release (other) | 30 days |

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.x | Active development |
| 1.x | Security fixes only |
| < 1.0 | Not supported |

## Responsible Use

WAFFEN must only be used against targets you own or have explicit written
authorization to test. Unauthorized use against systems you do not own is
illegal in most jurisdictions. The authors accept no liability for misuse.
